# 训练论文高频失败模式

本文件把训练论文和评审中反复出现的问题压缩成 coach 可执行检查项。具体历史案例只用于说明风险，不作为当前赛题规则。

## 1. 题意与模型

高风险问题：

- 问题重述和问题分析只是换句话重复；
- 题面条件漏读或自行补条件；
- 假设写了但模型中没有使用；
- 前后问题使用了不兼容的解释；
- 为了显得高级增加对结论没有贡献的模型。

修正动作：把每问的输入、输出、约束、依赖和验证写成模型合同，并让后续问题显式引用前问已冻结的结论。

## 2. 数学与代码不一致

典型硬伤：

- 正文和附录使用不同参数；
- 正文公式写一种约束，代码少一条或方向写反；
- 变量、单位、角度制、坐标原点不一致；
- 修改论文后仍引用旧 Run；
- 求解器显示 success 就直接宣称正确。

修正动作：Final Run 冻结前逐条回代关键约束；论文数字全部从唯一结果源回填。

## 3. 数值解释错误

典型问题：

- 误差数量级读错；
- 把相关性写成因果性；
- 把一次随机运行当稳定结论；
- 把局部最优/启发式最优写成全局最优；
- 用不适用于整数问题的连续灵敏度结论直接解释离散方案。

修正动作：每个强结论都附一个能支持它的验证或限定词。

## 4. 验证流于形式

低价值做法：

- 只画敏感性曲线，不解释是否影响决策；
- 只报残差，不给基准或量级解释；
- 所有问题都机械使用同一种验证；
- 检验指标没有对应代码或计算记录。

高价值做法：优先设计最可能推翻当前结论的验证，例如退化检验、独立实现互验、小规模精确对照、约束回代、步长/网格收敛、排序翻转检查。

## 5. 图表问题

常见扣分点：

- 图号重复或正文引用错号；
- 图很多但不能支持论点；
- 图后没有观察与结论；
- 字太小、单位缺失、图例不清；
- 图与正文使用不同版本数据。

修正动作：每张图建立来源 Run 和所支持 Claim 的映射。

## 6. 摘要问题

常见问题：

- 只讲方法，不给关键结果；
- 摘要数字与正文不一致；
- 写“精度高、效果显著”但没有量化证据；
- 背景过长，真正的方法和结果被挤压。

修正动作：摘要最后定稿，并从正文 Final Run 复制关键数字。

## 7. 结构与篇幅

篇幅长不等于质量高。常见低效内容包括：重复题面、重复流程图、同一公式多次解释、为了页数增加无论证作用的图表。

章节结构应服务于当前题目，不设置通用的最低页数、最低字数、最低图数。

## 8. 参考文献与表达

- 参考文献必须真实、相关、实际被正文使用；
- 不能为了数量凑文献；
- 符号首次出现要定义；
- 结论既要报数，也要解释题目语境中的意义；
- 提交前全文搜索 TODO、示例数据、旧文件名、重复图号和明显笔误。

## 9. 最终评审视角

制作和评审最好分离：完成一版后冻结，以“评委能否复现、能否找到证据、能否发现矛盾”的视角重新审阅，而不是继续以作者视角补内容。
