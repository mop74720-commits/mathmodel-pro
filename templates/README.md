# Templates

本目录提供由 `mathmodel-pro` 教练层维护的“真实比赛仓库初始化模板”。

当前主模板：`competition-repo/`。

设计来源分两部分：

1. 吸收 `chenboshuo/cumcm_template` 的论文工程思想：`reference / src / thesis(paper)` 职责分离、论文分章节、草稿/发布双模式、自动生成支撑材料目录；
2. 加入本项目的比赛证据链：`problem / models / runs / results / audit / ai`。

注意：这里只继承工程结构与构建思想，不把旧版 `cumcmthesis.cls` 当作当届官方格式。最终排版必须以当届官方规则/官方模板为准。
