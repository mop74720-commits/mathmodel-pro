# 验证阶段

验证不是固定清单打卡，而是主动寻找能推翻当前结论的证据。

## 最低候选集合

- 优化：约束回代、小规模精确对照、多初值/多 seed、上下界或 Baseline 比较。
- 预测：严格训练/验证划分、误差指标、残差、简单 Baseline、物理边界。
- 评价：权重扰动、排序稳定性、替代方法对比、指标方向检查。
- 动态系统：步长/网格/容差收敛、守恒或物理合理性、参数敏感性、退化情形。
- 几何/图论：边界案例、极端案例、独立算法/枚举小实例、结构性约束检查。

## Sensitivity

扰动幅度根据真实不确定性决定，不机械采用固定 ±10% / ±20%。重点观察：

- 数值是否变化；
- 方案/排序是否改变；
- 约束是否从满足变成违反；
- 结论是否跨过决策阈值。

## Self-Attack

只问一件事：**有没有合理证据能推翻当前结论？**

若有，优先做那个检验，而不是增加更多装饰性实验。

## Final Result Gate

- 每问唯一 Final Run 已指定；
- 关键约束已回代；
- 最可能推翻结论的验证已经完成；
- 强结论有对应证据；
- heuristic / limited search 的表述没有越界成“已证明全局最优”。
