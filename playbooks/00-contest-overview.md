# 竞赛总览 Playbook

> **定位：情景策略参考，不是执行阶段。** 仅在当前 Competition Repo 状态与本情景匹配时使用；不得因为文件编号或时间标签强制推进。


## 目标

在有限时间内形成“完整、正确、可解释、可复现、可提交”的论文，而不是追求理论上最复杂的方案。

## 三条主线

- 模型线：题面 -> 假设 -> 模型 -> 算法 -> 验证
- 证据线：代码 -> Run -> 表/图 -> Claim -> 论文
- 协作线：Issue/Task -> Branch -> Review -> Merge -> Main

## 决策优先级

正确性 > 可解释性 > 完整性 > 稳健性 > 创新性 > 复杂度
