# mathmodel-pro v0.5.0-alpha.1

这是 Route Selection Layer 的 alpha 验证版本，不是最终稳定版，也不代表
正式 `v0.5.0`。

## 新增

- Route Selection Layer prototype
- Route/Decision normalized contract
- External route-selection adapter boundary
- Route validator

## 架构保证

- 保留 Coach / SkillHub / Competition Repo 三层边界。
- 不新增第二套 Decision Engine、Router 或 Freeze Engine。
- Route Score 仅能作为 `proxy_only` 证据，不能直接触发 `freeze` 或 `promote`。
- 不允许自动写入 Competition Repo 的 `problem/FACTS.md`；Selection 证据必须经过归档和确认后再晋升。
- 不合并 `mathmodel-skills`，Competition Repo 仍是唯一正式事实源。

## 已验证

- Coach validation passed。
- Competition Template validation passed。
- Route/Decision validator valid-fixture check passed。
- Python compile check and `git diff --check` passed。
