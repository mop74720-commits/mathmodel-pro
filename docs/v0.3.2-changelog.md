# v0.3.3 Changelog

Patch driven by full-system rehearsal and integration audit findings.

- Coach changed from stage-first narration to state-first adaptive decision making.
- READ/MODEL/IMPLEMENT/VERIFY/WRITE concepts and time playbooks are retained only as situational references.
- Four Gates are redefined as per-question/per-artifact quality checkpoints, not a global state machine.
- Removed stale hard-coded Skill paths; SkillHub `registry.yaml` is now the routing source of truth.
- Deprecated the embedded Competition Repo template; independent `competition-template` is the only authoritative template.
- Updated authoritative repo paths to `models/<question>/METHOD_CONTRACT.md` and `runs/FINAL_RUNS.csv`.
- Added `state-first-coaching.md` and stronger Coach/SkillHub authority boundaries.
- Added release validation for version consistency, stale routes and duplicate template authority.
